# LingoCaster Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Chinese ⇄ English translation and dictionary lookup powered by [Youdao AI Cloud](https://ai.youdao.com)
- `Translate` command: search-as-you-type translation with phonetics, parts of speech, and web phrases
- `Translate Selection` command: translate the currently selected text, falling back to clipboard text
- Pronounce results with the built-in macOS voice (`⌘` + `↩︎`)
- Copy result and close (`↩︎`), open the result on Youdao web (`⇧` + `↩︎`)
- Automatic word splitting for `CamelCase` / `snake_case` / `kebab-case` queries
- Query history: type `*` to browse previous lookups
